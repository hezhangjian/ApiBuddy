# 工程状态与限制

## 模板与存储

- 文件可手工查看，但外部编辑后应刷新列表并重新打开模板。revision 用于检测通过应用产生的并发修改；直接手工改文件但不增加 revision 不在该保证内。
- 变量默认值、请求头和正文以明文保存。没有系统钥匙串、独立环境集或自动遮蔽功能。
- 关闭窗口前需保存；切换服务/模板和新建动作提供未保存修改提示，没有崩溃草稿恢复。
- 写入进程异常终止可能留下 templates/.write-lock。先确认没有 ApiBuddy 进程写入，再手动移除该空目录。不会自动按时间猜测锁过期。
- 隐藏 .tmp 文件是未完成原子保存的残留，不参与列表读取；先备份检查再清理。未知 schemaVersion、损坏 JSON、超大文件和符号链接会跳过并提示。
- 单模板同步文件操作在主进程执行，适合个人小型模板库；尚未做大量模板的性能基准。云同步目录、多机同时写入和断电持久性未专项验证。

## HTTP 与界面

- 原型的 RPC 监听早到竞态已改为 UI 先注册 requestId 再发请求；取消、超时、错误和成功分别报告终态。
- 限制 8 个同时请求，每个最多接收 8 MiB。UTF-8 文本解码，不支持二进制文件保存或其他字符集选择。
- SSE 仅以文本显示；没有事件解析、重连、脚本、认证向导或代理/证书配置。
- 正文中的变量替换不会自动做 JSON 转义，需通过预览确认。HTTP 重复头遵循 Fetch/Headers 的归并语义。
- 中文粘贴和请求回显不是完整 IME 合成测试；尚需人工验收真实拼音候选、撤销/重做、多显示器缩放和屏幕阅读器。
- macOS 桌面快捷键通过输入桥接实现；数字输入不支持 selectionStart，粘贴使用整值替换。

## 构建与分发

- TypeScript 类型库改为 ES2021，解决 SDK AggregateError 类型检查问题。
- 构建在临时源码快照中进行；缓存 SDK 和依赖保留原目录，临时产物不进 Git。
- 当前没有正式图标、Developer ID 签名、公证或自动更新发布。stable 仅是本地构建渠道名。
- 当前验证平台为本机 macOS arm64；Linux 和 Windows 未验证。

## 服务与 Agent

- 服务标识全库唯一，文件定位使用固定 UUID；服务目录、元数据、模板目录和文件拒绝符号链接。用户指定的数据根目录可以通过系统路径指向外部存储。
- 创建服务的写锁为 services/.write-lock，异常退出后的恢复原则与模板写锁一致。
- 生成的 CLI 是本地 Node 工具，Markdown 需由 Agent 主动读取；不提供 Agent 端自动发现/注册协议。独立 CLI 不依赖桌面常驻。
- 命名接口按服务隔离；request 支持服务地址下任意路径，不自动继承模板认证头。没有 OS 沙箱、网络白名单或凭据权限分配。CLI 保留调用者的网络/文件权限。
- CLI 支持 Node.js 18+ 的 API，自动测试使用本机 Node v23.9.0；尚未对所有 Node 次版本分别验收。生成示例采用 POSIX shell 引号，本轮仅验证 macOS。
- 唯一 CLI 启动器位于 APIBUDDY_DIR/bin/apibuddy，共享运行时位于 APIBUDDY_DIR/cli/apibuddy.cjs。服务标识由第一个参数指定，再定位独立模板目录。移动数据需一同保留目录结构，并确认 APIBUDDY_DIR。Markdown 中的清单是复制时的快照，--help 每次读取最新接口。
