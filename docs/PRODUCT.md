# 产品范围

## 已确定的体验原则

- 先让用户快速跑通一个真实请求，再展开工程细节；说明以可以复制的命令和实际操作为主。
- 服务 ID 让用户输入并预览命令；始终使用 `apibuddy orders` 形式，避免每个服务生成不同可执行文件。
- Agent 接入先提供一段能粘贴到任意 Markdown 的说明，不要求用户理解额外注册协议，也不自动修改 Agent 配置。

## 当前能力

ApiBuddy 面向个人日常 HTTP 调试，当前交付一个完整的请求模板循环：

1. 创建服务时填写名称与服务 ID（例如 orders），输入时预览 apibuddy orders <接口名>；选择服务后点击「新建接口」，通过弹窗填写名称、方法和路径/URL，创建后立即保存到列表并打开编辑器。
2. 写入 {{变量名}}，设置默认值并查看请求预览。
3. 命名、描述并保存到本地模板库。
4. 再次加载，修改变量后发送；可只临时执行，也可保存更新或另存副本。
5. 查看响应状态、耗时、Body、Headers 和 Raw；在 JSON 树中展开对象、搜索文本，或按 JSON Pointer 提取字段，必要时取消或复制结果。
6. 生成统一 apibuddy CLI，通过服务标识和接口名调用；未保存模板的路径也能通过 request 调用。面板列出全部接口的示例，一键复制给 Agent。

左侧模板库按服务隔离，支持搜索和刷新，左下角「本地存储」展开后显示实际目录。保存采用独立 JSON 文件，无数据库服务依赖。

新建接口复用服务地址并补齐路径变量，保存后在独立标签中打开；GET/HEAD 进入参数页，其他方法进入正文页。切换服务或接口保留旧标签及其修改。取消不改变原编辑内容；保存失败保留弹窗输入，可修正后重试。关闭有未保存修改的标签需选择保存、放弃或取消。

## 2026-10-26：长响应阅读与专注操作

- 响应搜索显示当前命中/总数，上一处、下一处循环导航并滚动定位；支持 ⌘/Ctrl+F、Enter、Shift+Enter，修正 Unicode 大小写转换造成的位置偏移。
- JSON 字段、字符串、数字、布尔和 null 分色；可切换自动换行，长行保留横向滚动。较大或节点过多的响应退回纯文本，复制保留完整文本。
- 请求/响应可一键单独放大，Esc 回到原比例；URL、发送与保存始终可见。⌘/Ctrl+B 收放侧栏，只看请求时 ⌘/Ctrl+F 会重新显示响应查找。
- 流式响应可自动跟随末尾，上滚暂停，点击恢复。复制成功提示短暂显示在原有底栏，保存状态使用原有工作区底栏，减少提示造成的正文跳动。
- 204 等无正文响应明确显示“响应正文为空”。

## 2026-10-26：让正文占据主要窗口空间

移除重复服务大标题、英文装饰标题、常驻帮助段落和大卡片留白。固定三行顶部区域：请求标签、名称/环境/保存工具栏、完整宽度的 URL/发送栏。请求与响应填满剩余空间，各自滚动；请求体编辑器跟随可用高度。

分隔线可拖动，聚焦后方向键微调、回车或双击均分；左右/上下布局分别保留比例。侧栏可收起，搜索快捷键自动展开并聚焦。内容宽度不足 660px 时自动上下排列。说明、存储路径、响应查找及字段路径按需展开；复制 cURL、另存副本和删除收在「•••」。

## 2026-10-26：连续调试

- 最多 20 个请求标签，服务、环境、编辑内容及修订号独立保存；后台请求在切换时继续执行，关闭标签取消该请求。
- 恢复工作区自动写入本机，重新启动恢复上次成功保存的标签和草稿。响应正文不持久化，恢复后不会自动发送请求。
- 每个服务最多 30 个环境，每个环境最多 100 个变量。同名环境变量覆盖模板默认值；环境不会写回接口模板。
- 粘贴单条 POSIX/bash cURL，预览方法、URL、请求头数量和正文长度，再导入为草稿。可复制当前环境下的实际 cURL。
- JSON 格式化与按需展开的树、最多 2000 处文本匹配高亮、JSON Pointer 字段提取、字段值和路径复制。
- 发送按钮与 URL 同行；保存、发送、新建标签、关闭标签、接口搜索支持快捷键。

当前不包含：团队协同、服务内文件夹、服务编辑/删除、秘密管理、脚本、OpenAPI 导入、multipart/文件上传、持久请求历史、二进制文件、SSE 协议解析和自动更新。当前功能和验证记录不等同于已全面超过 Postman。
